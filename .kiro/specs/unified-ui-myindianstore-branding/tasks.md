# Implementation Plan: Unified UI — MyIndianStore Branding

## Overview

Consolidate six separate Angular UI modules (ui-auth, ui-storefront, ui-checkout, ui-account, ui-admin, ui-main) into a single Angular 18 SPA (`unified-ui/`) with MyIndianStore branding. The implementation follows the module dependency graph in the design: project scaffolding first, then core services, shared components, feature modules, the Express.js BFF, Docker configuration, and finally workspace cleanup. Property-based tests (fast-check) are placed immediately after the services they validate.
